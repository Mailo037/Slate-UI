Use the kit

A folder, a link, a shared vocabulary

Start with three files

<link rel="stylesheet" href="slate.css">
<script src="slate.js"></script>
<body class="slate-ui">…</body>
<script>const dispose = SlateUI.init(document);</script>

Copy the fonts directory too. No framework, CDN, API key or build step is required. Use dispose() when a view unmounts.
